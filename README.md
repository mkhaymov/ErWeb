

## Try the sample artist package

A small example package is available under [`examples/sample-artist/`](examples/sample-artist/). To run it locally, serve the repository root over HTTP and open:

```text
http://localhost:8000/index.html?config=examples/sample-artist/config.json
```

The example references image assets already in this repository; it does not duplicate or upload artist images. See the folder's README for adaptation notes.
