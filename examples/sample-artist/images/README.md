# Sample image sources and attribution

The sample artwork JSON references externally hosted Wikimedia Commons images. They are loaded directly from Wikimedia; no copies are stored in this folder. The `images/` folder contains this note and a neutral sample logo. The repository's existing root `images/` directory is unchanged.

These generic viewer-demo labels are not original work titles or artist names. This is not a real artist portfolio; the images are historical photographs of art and artists.

1. **“Serena Lederer in her apartment with Elisabeth Lederer's portrait”** — historical photograph; check the file page for specific rights information. [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:Serena_Lederer_in_her_apartment_with_Elisabeth_Lederer%27s_portrait.webp). Direct image: `https://upload.wikimedia.org/wikipedia/commons/3/3b/Serena_Lederer_in_her_apartment_with_Elisabeth_Lederer%27s_portrait.webp`.
2. **“Alberto Bottillo at work making a linocut”** — verify the individual file's current license and attribution requirements before reuse. [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:ALBERTO_BOTTILLO_AL_LAVORO_DURANTE_LA_REALIZZAZIONE_DI_UNA_LINOLEOGRAFIA.jpg). Direct image: `https://upload.wikimedia.org/wikipedia/commons/a/a2/ALBERTO_BOTTILLO_AL_LAVORO_DURANTE_LA_REALIZZAZIONE_DI_UNA_LINOLEOGRAFIA.jpg`.

The Van Gogh and DANTE-DeGroux image links were removed from the sample because the direct image URLs were reported as unavailable. Wikimedia Commons files have different licenses; check each file's description page for current license, creator, and attribution requirements before reuse. Replace the demo URLs with images you own or are licensed to use when adapting the sample package.
