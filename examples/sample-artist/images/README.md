# Sample image sources and attribution

The sample artwork JSON references externally hosted Wikimedia Commons images. They are loaded directly from Wikimedia; no copies are stored in this folder. The `images/` folder contains this note and a neutral sample logo. The repository's existing root `images/` directory is unchanged.

These are generic viewer-demo labels, not the original work titles or artist names. This is not a real artist portfolio; the images are historical works or photographs of art and artists.

1. **Vincent van Gogh, “Peasant of the Camargue / Portrait of Patience Escalier”** — public domain per the Commons result. [File page and attribution](https://commons.wikimedia.org/wiki/File:Vincent_Van_Gogh_0023.jpg). Direct image: `https://upload.wikimedia.org/wikipedia/commons/7/7f/Vincent_Van_Gogh_0023.jpg`.
2. **“Serena Lederer in her apartment with Elisabeth Lederer's portrait”** — historical photograph; check the Commons source for the specific rights information. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/3/3b/Serena_Lederer_in_her_apartment_with_Elisabeth_Lederer%27s_portrait.webp`.
3. **“Portrait DANTE-DeGroux-87”** — verify the individual file page for creator and rights before reuse. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/d/d2/Portrait_DANTE-DeGroux-87.jpg`.
4. **“Alberto Bottillo at work making a linocut”** — verify the individual file's current license and attribution requirements before reuse. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/a/a2/ALBERTO_BOTTILLO_AL_LAVORO_DURANTE_LA_REALIZZAZIONE_DI_UNA_LINOLEOGRAFIA.jpg`.

Wikimedia Commons files have different licenses. Always check each file's description page for current license, creator, and required attribution before reuse. Replace the demo URLs with images you own or are licensed to use when adapting the sample package.
