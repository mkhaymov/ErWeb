# Sample image files

The sample JSON uses the JPEG files in this directory: `0.jpg`, `1.jpg`, `2.jpg`, and `3.jpg`. They are loaded from this package using relative URLs; no external image host is needed to display the sample.

The filenames and gallery labels are intentionally generic. Before reusing these files in a public portfolio, verify their source and usage rights and provide any required attribution. The repository's root `images/` folder is separate and unchanged.
