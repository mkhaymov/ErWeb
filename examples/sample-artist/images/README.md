# Sample image sources and attribution

The sample artwork JSON references these externally hosted Wikimedia Commons images. They are loaded directly from Wikimedia; no copies are stored in this folder. The `images/` folder is reserved for images an artist chooses to host alongside their own JSON package.

1. **Vincent van Gogh, “Peasant of the Camargue / Portrait of Patience Escalier”** — public domain. [File page and attribution](https://commons.wikimedia.org/wiki/File:Vincent_Van_Gogh_0023.jpg). Direct image: `https://upload.wikimedia.org/wikipedia/commons/7/7f/Vincent_Van_Gogh_0023.jpg`.
2. **“Serena Lederer in her apartment with Elisabeth Lederer's portrait”** — the Commons result identifies this historical photograph as public domain. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/3/3b/Serena_Lederer_in_her_apartment_with_Elisabeth_Lederer%27s_portrait.webp`.

These are demonstration images, not Elena Roginsky's work. Check each Commons file page for current license and attribution details before reusing an image in a public presentation. Replace these URLs with your own hosted images when adapting the sample package.
