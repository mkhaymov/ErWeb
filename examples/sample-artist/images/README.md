# Sample image sources and attribution

The sample artwork JSON references externally hosted Wikimedia Commons images. They are loaded directly from Wikimedia; no copies are stored in this folder. The `images/` folder contains this documentation only; the repository's existing root `images/` directory is unchanged.

1. **Vincent van Gogh, “Peasant of the Camargue / Portrait of Patience Escalier”** — public domain per the Commons result. [File page and attribution](https://commons.wikimedia.org/wiki/File:Vincent_Van_Gogh_0023.jpg). Direct image: `https://upload.wikimedia.org/wikipedia/commons/7/7f/Vincent_Van_Gogh_0023.jpg`.
2. **“Serena Lederer in her apartment with Elisabeth Lederer's portrait”** — historical photograph; check the Commons source for the specific rights information. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/3/3b/Serena_Lederer_in_her_apartment_with_Elisabeth_Lederer%27s_portrait.webp`.
3. **“Portrait DANTE-DeGroux-87”** — sample portrait image. The source result describes it as public domain, but verify the specific file page, creator, and rights before reuse. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/d/d2/Portrait_DANTE-DeGroux-87.jpg`.
4. **“Alberto Bottillo at work making a linocut”** — sample printmaking photograph. Verify the file's current license and attribution requirements before reuse. [Commons category/source](https://commons.wikimedia.org/wiki/Category:Photographs_of_works_of_art). Direct image: `https://upload.wikimedia.org/wikipedia/commons/a/a2/ALBERTO_BOTTILLO_AL_LAVORO_DURANTE_LA_REALIZZAZIONE_DI_UNA_LINOLEOGRAFIA.jpg`.

These are demonstration images, not Elena Roginsky's work. Wikimedia Commons hosts files under different licenses; check the individual file description page for the current license, creator, and required attribution before reuse. Replace these URLs with your own hosted images when adapting the sample package.
